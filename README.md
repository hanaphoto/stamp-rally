# スタンプラリー

NFCタグとQRコードで回る、イベントブース向けスタンプラリーWebアプリです。
ログインなし・サーバーなしで、記録は参加者の端末内（localStorage）だけに保存されます。

- 公開先：GitHub Pages
- 説明書：アプリ内の manual.html（参加者・主催者向け）
- 主催者用：qr.html（スポットごとのQRコードと、NFCタグ書き込み用URLの一覧・一括印刷）

## イベントごとに変える場所

`config.json` を編集します。

- `eventId`：開催ごとに変える（前の開催の記録と混ざりません）
- `eventName`：イベント名
- `eventPeriod`：開催期間。`enabled` を true にすると期間外はスタンプが押せません
- `spots`：スポット一覧（`id` は短く、`key` はスポットごとに違う推測できない文字列、`name` は表示名）
- `goals`：達成段階（`count` はスポット総数以下で、増える順に）

設定を変えたら、`sw.js` の `CACHE_VERSION` を上げてください（参加者の端末に古い設定が残らないようにするため）。

## 使い方の流れ

1. 最初に通信できる場所でアプリを開く（オフライン用の準備が終わると画面に表示されます）
2. 各スポットのNFCタグにタッチ（iPhoneは出てきた通知をタップ）するか、QRコードを読む
3. スタンプが集まると達成。全部集まるとコンプリート画面（達成日時＋達成コード）が出ます
4. コンプリート画面をスタッフに見せて景品・特典と交換します

## 注意

- iPhoneはSafariで使うのが標準です。ホーム画面に追加すると記録が別になることがあります
- 達成コードは目視確認用です。二重交換を完全に防ぐ仕組みではありません
- QRコード生成ライブラリ（lib/qrcode.min.js）は qrcode-generator（Kazuhiko Arase, MIT License）です
